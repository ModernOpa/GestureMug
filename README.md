# Multi-Modal Context-Aware AI Gesture Verification System

Advanced Computer Vision выпускной проект.

## 🚀 Обзор системы
Программный комплекс реализует **контекстно-зависимый интерфейс бесконтактного взаимодействия** на основе синергии глубокого обучения, пространственного Raycasting-анализа и метрического обучения (Metric Learning). Система распознает уникальный жест руки (`Шака` большим пальцем вниз) и верифицирует его выполнение в отношении конкретного физического объекта (`кружка`), определяя его принадлежность к базе данных зарегистрированных подписчиков.

Проект построен по канонам Enterprise-разработки на принципах **SOLID** с использованием фабричных паттернов, строгой статической типизации (`typing.cast`, `Pyright`, `Mypy`) и полной инкапсуляции настроек.

## 🛠 Технологический стек и синергия компонентов

Проект демонстрирует бесшовную интеграцию передовых ИИ-технологий, где каждый модуль выполняет свою изолированную задачу, передавая результаты через стандартизированные структуры данных:

*   **Детекция и Сквозной Трекинг (YOLO + ByteTrack):** Локализация целевых объектов (`cup`) на GPU **NVIDIA RTX 5060 Ti** с использованием ядер **CUDA 13.0**. Алгоритм ByteTrack присваивает объектам сквозные `track_id`, сохраняя их историю даже при кратковременных перекрытиях (окклюзиях).
*   **Экстракция 3D-Скелета Руки (MediaPipe Tasks API 1.x):** Извлечение 21 пространственной координаты суставов кисти руки в реальном времени.
*   **3D Raycasting и Z-глубина (Бизнес-логика):** Математический аппарат (NumPy) строит вектор направления луча от сустава к кончику большого пальца. Алгоритм разрешает 2D-неоднозначности перекрытия планов (когда объекты стоят друг за другом): система ранжирует пересеченные лучом объекты по площади их Bounding Box (эвристика удаленности по оси Z) и выбирает истинную кружку на переднем плане.
*   **Metric Learning / Реидентификация (OpenAI CLIP ViT-B/32):** Вырезанный фрагмент кадра (`Crop`) трансформируется в 512-мерный вектор признаков (эмбеддинг). Модуль базы данных вычисляет *Косинусное сходство (Cosine Similarity)*, мгновенно сверяя объект с базой подписчиков.
*   **Многопоточный Синтез Аудио (FFmpeg + Pydub):** Так как OpenCV нативно не поддерживает работу со звуком, система фиксирует миллисекунды событий, генерирует аудиодорожку и в финале асинхронно мультиплексирует видео и звук через утилиту `FFmpeg` в монолитный контейнер MP4.

## 🏗 Архитектура Визуализации: Widescreen HUD Dashboard

Приложение реализует современный концепт широкоформатного аналитического дашборда (общее разрешение окна `1680x720`), разделенного на две функциональные зоны:
1.  **Зона Видеопотока (1280x720):** Динамический AR-оверлей. Отображает рамки YOLO, скелет MediaPipe, а в моменты триггеров накладывает неоновый зеленый круг-прицел (при успешной авторизации) или перечеркивает объект красным крестом (при попытке несанкционированного доступа).
2.  **Сайдбар Системного Мониторинга (400x720):** Выводит текущую производительность (FPS), счетчик зафиксированных событий, графический статус безопасности (`ACCESS GRANTED` / `ACCESS DENIED`) и интерактивную ленту последних 5 событий с цветовым кодированием строк и секундными таймстампами.

## 📂 Структура Репозитория

*   `config.py` — Неизменяемая конфигурация приложения (`Singleton` на `@dataclass(frozen=True)`).
*   `interfaces/` — Абстрактные контракты классов (`IDetector`, `IDatabaseClient`) для декуплирования вендор-зависимостей.
*   `modules/` — Реализации модулей:
    *   `video_stream.py` — Фабрика видеопотоков (`VideoStream`), бесшовно переключающаяся между файлом (MP4) и сетевым TCP-сокетом камеры.
    *   `object_detector.py` — Детекция YOLO + трекер ByteTrack.
    *   `hand_detector.py` — Архитектура MediaPipe Tasks API 1.x.
    *   `spatial_logic.py` — Геометрический 3D Raycasting анализатор.
    *   `clip_encoder.py` — Экстрактор эмбеддингов OpenAI CLIP.
    *   `vector_db.py` — In-Memory векторный индекс базы подписчиков (Cosine Similarity).
    *   `mock_db.py` — Журналирование структурированных JSON-логов.
*   `admin_register.py` — Панель администратора для внесения новых объектов в базу подписок.
*   `main.py` — Главный оркестратор конвейера с интегрированными Smoke-тестами.

## 💻 Порядок Развертывания

1. Развернуть виртуальное окружение:
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
2. Скачать веса MediaPipe Hands:
```bash
wget -P data/hand-models/ https://googleapis.com
```
3. Запустить систему: `python3 main.py`
*Для выхода из графического окна нажмите клавишу **Esc** или **q**.*
